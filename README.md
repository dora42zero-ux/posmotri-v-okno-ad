# Посмотри в окно

Одностраничное приложение для просмотра видео из разных городов. Можно искать ролики по названию города и времени суток, переключать основное видео выбором карточки и загружать следующую порцию результатов.

## Запуск

Откройте файл index.html в современном браузере. Установка зависимостей и сборка не требуются.

Для загрузки роликов приложению нужен доступ к API Яндекс Практикума.

## Структура

- index.html — разметка страницы и шаблоны карточек.
- styles/style.css — лейаут и оформление интерфейса.
- styles/preloader.css и styles/error.css — состояния загрузки и ошибки.
- scripts/script.js — поиск, загрузка карточек и переключение видео.
- fonts/ — шрифты проекта.
